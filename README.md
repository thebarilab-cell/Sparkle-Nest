# Pristine Presence

Create a premium conversion-focused website for COMPANY_NAME.
General Requirements:
- Build a premium responsive website using HTML, CSS, JavaScript.
- White + Sky Blue + Emerald Green color palette.
- Modern animations, SEO optimized, fast loading.
- Sections: Hero, About, Services, Why Choose Us, Portfolio/Gallery, Testimonials, Process, FAQ, Contact, Footer.
- Mobile-first, semantic HTML, clean UI, strong CTAs.

Business Type: Cleaning Companies
Services: House, Office, Deep Cleaning, Carpet, Window, Move In/Out. CTA: Book Today.
Design the website like an award-winning agency with luxury UI/UX, bold typography, subtle animations, glassmorphism accents, premium icons, trust badges, and conversion-focused layout. Include engaging micro-interactions, sticky navigation, CTA buttons, contact form, Google Maps placeholder, and fully responsive design. Generate complete HTML, CSS and JavaScript files. Create clean semantic HTML. Do NOT use Bootstrap. Everything should be custom designed. The website must look premium enough to impress clients immediately. Generate all HTML, CSS and JavaScript files. Use only high-quality, realistic, niche-specific images throughout the website. Every section should feature images that match the business type (e.g., roofing for roofing companies, dentists for dental clinics, plumbers for plumbing companies). Avoid generic placeholders, low-quality stock photos, cartoons, or AI-looking images. The visuals should look premium, professional, and trustworthy.
